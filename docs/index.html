DropStop

Temporarily pause Dropbox syncing with a single click or command. Set a timer, walk away, and it resumes automatically.

Download for Windows View CLI Usage

Features

⏱️ Timed Pause

Pause Dropbox for 1 minute, 5 minutes, an hour, or any custom duration. Decimals supported — even 30 seconds.

🖥️ System Tray

Lives quietly in your system tray. Right-click for quick actions. Double-click for a live status window with countdown.

💻 Command Line

Full CLI support. Script it, schedule it, or run it from your terminal. Perfect for power users.

🟢🔴 Visual Status

Green icon when Dropbox is running, red when paused. Know your sync state at a glance.

🔔 Notifications

Balloon notifications when pausing and resuming. Can be toggled off if you prefer silence.

♾️ Indefinite Pause

Need Dropbox off for a while? Pause indefinitely and resume manually whenever you're ready.

How It Works

1

Pause

Choose a duration from the tray menu or run dropstop -t 5 from the command line.

2

Wait

Dropbox is stopped. The tray icon turns red and a countdown begins.

3

Resume

When the timer expires, Dropbox restarts automatically. Or resume early with dropstop -r.

Command Line Interface

# Pause Dropbox for 5 minutes
> dropstop -t 5
 
# Pause for 30 seconds
> dropstop -t .5
 
# Pause indefinitely
> dropstop -t 0
 
# Resume Dropbox (overrides any timer)
> dropstop -r
 
# Check current status
> dropstop -s
Dropbox process: Stopped
DropStop state: Paused
Remaining: 03:42
